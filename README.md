*********************************************************************BusDotGo Bus Application****************************************************************************************************

A console-based Java bus booking application. Users can view buses, create bookings, check booking status, and exit the application. Administrators can manage buses and bookings.

->User Features

- View available buses
- Book a bus seat
- Validate bus and seat numbers
- Prevent booking when a bus is full
- View booking status
- Handle invalid numeric input safely
- Reserve seats and reduce available seat count
- Exit the application

->Admin Features

- Admin login
- View all buses
- Add a new bus
- Select and view a bus
- Remove a bus
- View booking logs
- Remove a booking
- Exit the admin menu
